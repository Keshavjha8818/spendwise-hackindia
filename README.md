# SpendWise — Student Expense Tracker

A responsive, student-first expense tracker created for the HackIndia UI/UX skill challenge.

## Screens / flows
1. **Overview** — budget summary, remaining balance, category mix, and recent transactions.
2. **Transactions** — searchable and filterable transaction history, including a useful empty state.
3. **Insights** — category breakdown and practical spending habits.
4. **Add expense flow** — validated form, category selection, date selection, success feedback, and error copy.
5. **Edit budget flow** — update the monthly budget and see all totals recalculate.
6. **Appearance toggle** — switch between light and dark themes.

## Run locally
No build tools or dependencies are required.
- Download or clone this repository.
- Open `index.html` in a modern browser.

## Files
- `index.html` — semantic page structure and dialogs.
- `styles.css` — responsive layout, typography, contrast, and themes.
- `app.js` — navigation, calculations, filters, form validation, empty states, and interactions.

## Notes
The starter transactions are demo data for the November 2026 presentation. Data is held in browser memory and resets on refresh; this is a front-end demonstration, not a production finance application.
